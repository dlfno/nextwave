# Nextwave hackathon demo

## One-command container demo

```sh
docker compose -f compose.demo.yaml up --build
```

Open `http://localhost:4000`. The stack starts PostgreSQL, applies migrations,
creates ephemeral development ES256 keys, starts the Express API, and serves the
Angular SSR application. Register a new user to run the persisted end-to-end flow.

The signing keys generated by the container entrypoint are intentionally ephemeral
and suitable only for the hackathon demo. Supply managed keys through
`MANDATE_SIGNING_PRIVATE_JWK` and `VUELAYA_SIGNING_PRIVATE_JWK` outside the demo.

## Trial-by-fire browser suite

From `front/`:

```sh
npx playwright install chromium
npm run e2e
```

The suite covers the $130 happy path, checkout-specific human approval, $300
denial, live revocation, human/merchant/auditor evidence, disputes, and desktop and
mobile viewport fit. It uses the deterministic presentation routes, so it does not
require a database and remains reliable during judging rehearsals.
